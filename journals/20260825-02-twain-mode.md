# Make two disjoint lines the default Twain game

> Immutable episodic record. Do not edit; supersede with a newer journal.

## Context

The initial game used the Twain identity for a single Hamiltonian path. The product mechanic now needs to embody that name directly: one player draws line A and line B, each through its own numbered sequence, and the two lines must divide the entire board without sharing a cell. The original one-line game remains available as Classic. This changes the single-path conclusion in `20260824-01-project-foundation.md`; its identity, static-runtime, and witness-first decisions still stand.

During implementation, an early UI concept showed each line's generated witness length as a target. That would have implied that the witness partition was the only accepted answer, even though puzzle uniqueness is not guaranteed.

## Decision process

- Keep one shared v2 puzzle shape with `mode` and a `lines` array rather than branching the runtime around separate Classic and Twain schemas.
- Make Twain the default and encode `mode` in reproducible URLs. The project is unpublished, so a deliberate version-2 schema replacement is simpler than preserving version-1 boards or mode-less Classic links.
- Continue generating one seeded Hamiltonian path, then split it between 40% and 60%. Reverse the suffix to form line B and wall off the adjacent final endpoints. This preserves a cheap constructive solvability proof while creating two independent start-to-finish directions.
- Give A and B independent clue sequences and visually distinguish them by text, shape, and color. Active-line controls, pointer target ownership, and A/B keyboard shortcuts all select which pure transition receives the next cell.
- Keep Undo and Clear global because the action history is player-wide, while drag-back trims only the active line.
- Reject per-line quotas. Completion validates each line's endpoints, clue order, adjacency, walls, and non-repetition, then validates that their disjoint union fills the board. It never compares player line lengths with witness line lengths.
- Keep deterministic hints witness-based. A hint may canonicalize an alternate path or partition, which is acceptable because Hint promises progress along one known answer rather than preservation of every possible answer.

## Outcome

- Twain is the default two-line mode; Classic is a selectable single-line mode.
- Puzzle format version 2 stores `mode`, `lines[].id`, `lines[].clues`, and `lines[].solution`. Determinism is scoped to `(version, mode, difficulty, seed)`.
- The generator and validator guarantee one or two disjoint witness lines whose union covers every cell. Twain always includes a wall between the two witness endpoints at the split.
- Game state stores a path per line, an active line, and global cross-line history. Pointer, touch, and keyboard input continue to share `src/game.js` transitions.
- A line may reach its final clue before the other line. The game completes only when both valid lines collectively occupy the whole board.
- The UI displays only total occupied cells over board cells. It exposes no A/B cell target, and alternate valid partitions with different line lengths are accepted.
- Multiplayer and social collaboration remain outside the current single-player scope.

## Trade-offs and consequences

The generated witness split is balanced, but player solutions need not be. This keeps correctness aligned with non-unique boards at the cost of providing no line-length guidance. The generator still proves existence rather than uniqueness or human difficulty, so some boards may admit several paths or partitions. Version-1 reproducibility was intentionally dropped instead of adding compatibility branches.

The visual system now carries more state. Line A uses round dark clues and an orange route; line B uses rounded-square navy clues and a teal-blue route. Labels and shapes preserve the distinction without depending only on color.

- A dedicated regression proves a valid 8/4 player partition is accepted for a puzzle whose stored witness partition is 4/8. Static coverage proves Twain is the default and no per-line quota element exists.
