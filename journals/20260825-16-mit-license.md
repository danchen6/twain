# Release Twain under the MIT License

> Immutable episodic record. Do not edit; supersede with a newer journal.

## Context

The repository had no explicit software license, leaving reuse and distribution rights unstated. Dan Chen requested an MIT license under his name.

## Decision process

Use the standard MIT License text with `Copyright (c) 2026 Dan Chen`. Keep the full legal terms in a root-level `LICENSE`, expose the license in the README for human readers, and declare `MIT` in package metadata for tooling. No custom terms are added because they would make the license non-standard and create ambiguity.

## Outcome

Twain is licensed under the MIT License with Dan Chen as the copyright holder. The root license file is the authoritative grant; README and package metadata point to the same license.

## Trade-offs and consequences

MIT permits broad use, modification, redistribution, sublicensing, and sale as long as the copyright and permission notices are preserved. It disclaims warranties and does not provide reciprocal source-sharing requirements or an explicit patent grant.
